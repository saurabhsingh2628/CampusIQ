# CampusIQ

## AI-Powered Student Intelligence and Career Management System

CampusIQ is a full-stack platform that combines academic performance analytics, career guidance, resume analysis, skill-gap analysis, job matching, and placement preparation into a unified system.

## Technology Stack

- Next.js
- TypeScript
- Tailwind CSS
- FastAPI
- Python
- PostgreSQL
- Supabase
- Gemini API
- Machine Learning
- scikit-learn
